# Website README

Open `index.html` in a browser to use the upgraded campaign dashboard.

## What changed

- Rebuilt the site as an offline-first single-page dashboard.
- Added current Bookmark 5 state: Nightstone recovery, Rillix the tressym, Goldenfields chosen.
- Added dashboard cards for current location, next action, active quest, rules warning, and party terms.
- Added embedded document reader so local Markdown files display without browser fetch/file permission problems.
- Added searchable document list.
- Added party, inventory, NPC, timeline, and quest sections.
- Added print support and dark/light theme toggle.
- Preserved the old `index.html` as `index.backup-before-upgrade.html`.
